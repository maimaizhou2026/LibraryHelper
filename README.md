# 📚 浙杭借书搭子 (LibraryHelper)

打通 **浙江图书馆** 与 **杭州图书馆（含全城各区县总分馆 / 主题分馆）** 的个人借阅管理、防重借秒搜与全馆书库联查 Web 工具。

> **隐私声明**：所有个人借阅记录、星级评分、借阅评价标记、自定义分类标签与读书笔记 **100% 存储在您本地浏览器的 IndexedDB 与 localStorage** 中，支持离线极速检索，不上传任何第三方云端数据库。

---

## ✨ 项目背景与解决痛点

浙江图书馆与杭州图书馆官方借阅系统存在以下高频痛点：
1. **历史借阅记录无法跨馆/拼音检索**：借过数百本书后（尤其是《航海王》《哈利·波特》《赛雷三分钟漫画》等长篇系列丛书），在书架前无法快速确认某卷是否借过、读到哪一卷。
2. **双馆账本割裂**：浙图与杭图各自独立，同名书跨馆重复借阅难以察觉。
3. **找书位置与地图导航繁琐**：分馆众多，缺少一键查看在馆状态、场馆详细门牌地址复制、百度地图/手机地图精准建筑定位以及浙图之江馆 3D 书架层架位直达能力。

**「浙杭借书搭子」** 将双馆个人借阅记录导出汇总至本地数据库，结合双馆实时馆藏联查与 3D 书架导航，提供一站式找书、防重借与读书笔记体验。

## 🚀 核心功能特性

- **📚 搜我的借阅（支持 100% 离线操作）**
  - **拼音/首字母/同义词秒搜**：支持书名、作者、全拼、拼音首字母（如输入 `st` 搜《三体》、`hlbt` 搜《哈利·波特》、`海贼王` 自动关联《航海王》）、ISBN、索书号、分馆与读书笔记检索。
  - **同系列自然卷号排序**：自动识别中文数字（`卷一~卷九十`、`壹~拾`、`上/中/下`）、阿拉伯数字、无卷号首卷，以及《航海王》主线分篇（`砂之国·卷十三`）与衍生特例（`专题书`、`总集篇`）分组排序。
  - **跨馆书名自动去重与借阅流水切换**：自动合并同一本书在浙图/杭图的多次借阅记录，清晰展示借阅次数、在借倒计时与历史流水。
  - **个人阅读资产管理**：支持 `值得重借 / 推荐喜欢 / 未读完下次再借 / 踩雷别借` 标记、5 星评分、分类标签（`睡前绘本 / 科幻 / 历史 / 二刷 / 踩雷` 等）及读书笔记；重新同步或更新借阅记录时 **100% 自动保留历史评价与笔记**。
- **🌐 在线搜浙图/杭图全馆书库**
  - **双馆实时联查與分馆过滤**：支持按浙图 5 大馆区、杭图市民中心总馆、直属专业主题分馆及杭州 13 个区县总馆定向过滤，默认开启 **「🟢 只看有书」**。
  - **下拉滚动无限加载与全局平滑重排**：滚动到底部自动加载后续页，跨页加载同系列丛书时自动重排卷序并保持视口锚定不跳动。
  - **内联秒开分馆状态 / 地图精准定位 / 3D 书架导航**：
    - 点击卡片底部直接内联展开各分馆在馆状态（总馆优先、在馆优先、同馆聚合、已知地址优先）；
    - 点击 **「地址」** 浮层显示详细门牌地址并自动复制到剪贴板；
    - 点击 **「地图」** 在 PC 端直达百度地图 17 级比例尺场馆建筑点位，在手机端唤起系统地图 App；
    - 浙图之江馆在馆开架图书支持一键打开 **「之江馆 3D 书架导航（精确到区/架/面/列/层/位）」**。
- **🔄 双馆一键同步与在线续借**
  - **杭州图书馆**：支持身份证/市民卡/读者证号 + 密码直连同步（自动处理 RSA 加密与算术验证码识别），自动配对合并历史借还流水。
  - **浙江图书馆**：支持读者证密码（SM2 国密加密）及微信/支付宝扫码登录同步。
  - **顶部一键同步 & 在线续借**：支持保存账号密码后一键同步双馆最新借阅数据，并在详情页直接查看剩余续借次数、一键在线续借。
- **📱 PC 宽屏 + 移动端双排版自适应**
  - 内置 `PC 宽屏视图` 与 `手机端预览框 (412px)` 一键切换，真机移动端自动适配紧凑卡片排版。

### 🛠️ 如何自定义修改或新增分馆地址？
所有分馆下拉选项、别名匹配词、门牌地址及百度地图坐标均已独立抽离至 `addr/` 目录下的两个 JSON 文件中，方便直接人工编辑维护：
- **`addr/zjlib_branches.json`**：维护浙江图书馆各馆区下拉菜单（`dropdownOptions`）、馆区 ID 映射（`districtIdMap`）及场馆地址坐标（`branches`）。
- **`addr/hzlib_branches.json`**：维护杭州图书馆总馆、直属主题分馆、13 个区县总馆的下拉菜单（`dropdownOptions`）、市民中心总馆内部借阅室列表（`mainCenterRooms`）及场馆地址坐标（`branches`）。

修改这两个 JSON 文件后，前端「在线搜索分馆下拉框」、馆藏列表「地址浮层」与「百度地图精准定位」会自动同步生效。

## 💻 本地开发与运行

### 环境要求
- **Node.js** `>= 18.0.0`（推荐 Node 20 LTS）
- **npm** `>= 9.0.0`

### 启动步骤
```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器（同时启动前端与双馆 /api/* 代理中间件）
npm run dev
```
启动后在浏览器访问：`http://localhost:5173/`（局域网手机测试可直接访问终端输出的 `http://192.168.x.x:5173/`）。

## 🌐 在线部署指南（默认采用方案 B 全功能部署）

由于浙江图书馆（`www.zjlib.cn`）与杭州图书馆（`my1.zjhzlib.cn` / `opac.zjhzlib.cn`）官方接口存在浏览器跨域（CORS）限制及 Cookie/国密加密要求，本项目已内置 **方案 B（前端 + `/api/*` 轻量代理层）** 自动化配置：

### 方式 1：推送到 GitHub 后使用 Vercel 一键全功能部署（推荐，零服务器成本）
项目根目录已配置好 `vercel.json` 与 `api/[...path].ts` Serverless 函数入口：
1. 将本仓库代码推送到您的 GitHub 仓库；
2. 打开 [Vercel](https://vercel.com/) 并使用 GitHub 登录，点击 **Add New... -> Project**，导入该 GitHub 仓库；
3. 保持默认配置直接点击 **Deploy**；
4. 部署完成后即可获得在线 HTTPS 网址，**完整支持在线搜浙图/杭图全馆书库、输入账号密码直连同步、微信/支付宝扫码登录、在线续借与自动封面补全**。

### 方式 2：自有云服务器 / NAS / Docker（Node.js 生产环境一键运行）
`vite.config.ts` 中的 `librarySyncProxyPlugin` 已同时挂载至开发服务器（`configureServer`）与生产预览服务器（`configurePreviewServer`）：
```bash
# 1. 构建前端生产包
npm run build

# 2. 启动生产服务（默认监听 0.0.0.0:5173，同时提供静态页面与 /api/* 接口服务）
npm start
```

### 补充：纯离线 / 纯静态环境使用说明
在无后端或断网环境下，一旦您完成了首次借阅记录同步（或通过「导入记录 -> JSON 备份文件」导入数据），**「📚 搜我的借阅」下的所有搜索、拼音匹配、分馆/状态/年份筛选、自然卷号排序、现场借书查重雷达、星级评分、标签管理、读书笔记编辑与 JSON/CSV 导出均 100% 在浏览器本地离线运行**。
